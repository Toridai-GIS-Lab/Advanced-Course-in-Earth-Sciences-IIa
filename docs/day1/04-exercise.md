# 4. ミニ演習

**形式：演習（約60分）＋共有（約20分）**

## 課題

!!! abstract "お題"
    **倉敷市** について、次の2つを作成してください。

    1. 平面直角座標系 第V系（EPSG:6673）の、倉敷市の範囲で切り抜いた標高ラスタ（COG）
    2. 同じ範囲・同じ座標系の土地利用ベクタ（GeoPackage）

## 手順

### Part A：CLIのみで作る（30分）

- `data/raw/` のデータから出発する
- 使ったコマンドを、**順番どおりに** `exercise_cli.sh` に書き残す
- 最後に `gdalinfo` / `ogrinfo` で結果を確認する

### Part B：QGIS（GUI）で同じものを作る（20分）

- 同じ元データから、同じ成果物を作る
- 何をクリックしたか、**手書きで** メモする

### Part C：比較する（10分）

| 観点 | CLI | GUI |
|------|-----|-----|
| かかった時間 | | |
| 手順の記録の長さ・正確さ | | |
| 結果は一致したか（範囲・画素数・地物数） | | |
| 「総社市でもやって」と言われたら？ | | |
| 隣の人に手順を渡せるか？ | | |

!!! tip "比較のヒント"
    QGIS の「処理」→「履歴」を開いてみてください。GUIで実行した処理の GDAL コマンドが記録されているはずです。
    **GUIの裏でも、同じコマンドが動いていた** ことを確かめましょう。

## 共有（20分）

- 隣の人と `exercise_cli.sh` を交換し、相手のスクリプトで **同じ結果が出るか** 実行する
- 出なかった場合、何が原因だったか（パス、ファイル名、手作業の混入、…）

    - [ ] 自分の処理を、他人が実行できる形で書き残せた
